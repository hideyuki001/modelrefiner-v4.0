## 0. Overview

This document defines the **cross-locale translation and creativity matrix** used in  
ModelRefiner v4.0’s *Creative Induction Layer (HeartScape × SYNAPSE)*.

It formalizes how **emotion**, **structure**, and **symbolism** interact  
across languages, enabling *reproducible cultural creativity*.

## 1. Conceptual Framework

| Dimension | Definition | Example |
|------------|-------------|----------|

## 2. Cultural Adaptation Axes

| Axis | Description | Example (EN→JA) |
|------|--------------|-----------------|
| **Emotion Arc** | Maps emotional progression | “Never alone” → “Silence as companion” |
| **Symbolic Palette** | Local imagery, metaphoric motifs | “Fire” → “Lantern light” |

| **Prosody Alignment** | Meters, mora/stress, rhythm | 7–5 mora in JA lyric form |
| **Cultural Distance (ΔC)** | Degree of cultural transformation | 0.2 = light adaptation, 0.8 = deep reinterpretation |

## 3. Creative Operators (SYNAPSE Layer)

| Operator | Function | Example |
|-----------|-----------|----------|
| **AmplifyEmotion** | Heighten emotional tone | “hope” → “radiant hope” |
| **PivotMetaphor** | Change metaphor source/target | “storm” → “journey” |
| **CulturalTransposition** | Replace foreign imagery with native | “Hollywood dream” → “morning sun dream” |
| **ProsodyWeave** | Adjust rhythm/sound pattern | Add mora balance or vowel resonance |
| **Counterpoint** | Introduce contrast or echo | “loss” ↔ “light” |
